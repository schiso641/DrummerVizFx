# Drummer Viz — VST3-ЭФФЕКТ для Ableton (барабанщик по нотам Superior Drummer)

Это **аудио-эффект**: ставится на дорожку Superior Drummer **после** него. Звук идёт насквозь (плагин
задерживает его на 100 мс, Ableton это компенсирует). Внутри окна — тот же барабанщик, что в drummer.html
(вид сверху и от первого лица).

## Как барабанщик узнаёт ноты
Ableton **не отдаёт MIDI аудио-эффектам**, поэтому два способа:
1. **Ноты из MIDI-файла (точно, по умолчанию).** Экспортируй клип, который играет Superior Drummer
   (в Ableton перетащи MIDI-клип на рабочий стол — получится .mid), нажми в плагине **Open MIDI…**.
   Дальше барабанщик идёт синхронно с транспортом Ableton (позиция в долях, темп, петля, перемотка),
   а руки заранее «видят» следующие удары. Если клип стоит не с начала проекта — подвинь **Start offset**
   (в долях: 4 = один такт). Файл сохраняется внутри проекта Ableton.
2. **Слушать звук (экспериментально).** Плагин делит звук на 5 полос каждые 5 мс, страница угадывает бочку/снейр/хэт/том/тарелку.
   На моих проверках по синтетическим барабанам точность средняя (бочка и снейр лучше, хэты и томы хуже),
   на реальных сэмплах EZX и с реверберацией будет ещё хуже. Для точной игры используй режим 1.

## Сборка без установки программ (через GitHub, с телефона тоже можно)
1. Создай на github.com новый репозиторий и загрузи в него **всё содержимое этого архива**
   (включая папку `.github`).
2. Вкладка **Actions → Build VST3 → Run workflow**. Через 5–10 минут внизу страницы запуска появятся
   файлы **DrummerViz-windows-latest** и **DrummerViz-macos-latest** — скачай нужный.
3. Если сборка упала, открой лог шага Build и пришли мне красные строки — поправлю.

Локально: `cmake -B build -DCMAKE_BUILD_TYPE=Release` и `cmake --build build --config Release`
(нужны Git, CMake 3.22+, Visual Studio 2022 или Xcode).

## Установка
- Windows: файл `Drummer Viz.vst3` → `C:\Program Files\Common Files\VST3\`. Нужен Microsoft Edge WebView2 Runtime
  (есть в Windows 11 и в обновлённой Windows 10).
- macOS: → `~/Library/Audio/Plug-Ins/VST3/`; если macOS ругается на неподписанный файл:
  `xattr -dr com.apple.quarantine "~/Library/Audio/Plug-Ins/VST3/Drummer Viz.vst3"`.
- Ableton: Preferences → Plug-Ins → включи VST3 (System Folders) → Rescan. Плагин в категории Audio Effects.

## Важно
